# Live Streaming YouTube & Reader Kitab Digital

Aplikasi web interaktif untuk menyimak live streaming pengajian YouTube berdampingan dengan pembaca kitab berbasis PDF (PDF.js).

## Fitur Utama
- **YouTube Live Stream Embed**: Memuat live streaming atau video YouTube hanya dengan menempelkan URL/ID.
- **Kitab PDF Reader**: Render file PDF kitab langsung di browser dengan kontrol navigasi halaman dan zoom.
- **Overlay & Running Text**: Menampilkan status live dan pesan running text pengumuman.
- **Mode Dual Panel Responsif**: Tampilan terbagi rapi di layar desktop maupun smartphone.
- **Dark/Light Theme**: Dukungan tema gelap dan terang.

## Cara Menggunakan
1. Buka aplikasi di browser.
2. Masukkan URL / ID video YouTube Live pada kolom atas, lalu klik **Muat Stream**.
3. Pilih dan unggah file PDF kitab melalui tombol **Buka PDF Kitab**.
4. Gunakan navigasi panah di atas PDF untuk berpindah halaman atau menyesuaikan ukuran (zoom).
